## Tasks Covered

### Task 1: Creating NumPy Arrays

* 1D array from 1 to 10
* 2D array of shape (3, 3) with values from 1 to 9
* Array creation from a Python list
* Display of shape and data type

### Task 2: Mathematical Operations

* Addition
* Subtraction
* Multiplication
* Division
* Power operation
* Use of NumPy mathematical functions

### Task 3: Important NumPy Mathematical Formulas

* Square root
* Exponential
* Natural logarithm
* Sum
* Cumulative sum

### Task 4: Aggregation Operations

* Row-wise sum
* Column-wise sum
* Minimum and maximum values
* Overall mean

### Task 5: Statistical Operations

* Mean
* Median
* Variance
* Standard deviation
* Minimum and maximum
* Range

### Task 6: Percentiles and Sorting

* Sorting the array
* 25th, 50th, and 75th percentiles
* Count of values above average

### Task 7: Mini Use Case – Sales Analysis

* Total weekly sales
* Average daily sales
* Highest and lowest sales
* Standard deviation of sales
* Identification of days with above-average sales



## How to Run the Program

1. Ensure Python is installed on your system.
2. Install NumPy if not already installed:

```bash
pip install numpy
```

3. Run the Python file:

```bash
python numpy_assignment.py
```

The output for each task will be displayed clearly in the terminal.
